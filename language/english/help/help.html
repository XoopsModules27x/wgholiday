Help: wgHoliday

wgHoliday

Holiday and event management for XOOPS

Create, manage and display time-based holidays, announcements and events on your XOOPS website.

Version 1.0.0 · Beta 1

Welcome

Welcome to the wgHoliday help page. This module provides a flexible way to manage holidays and other time-dependent events in XOOPS.

Events can contain a title, header, body, footer and image. You can define when an event is active and decide how and where it should be displayed to your visitors.

The basic idea of wgHoliday is to shown information about an event as a block and with a modal. The modal is intended to ensure that all website visitors see the important event information immediately.
Tip: wgHoliday is not limited to public holidays. You can also use it for seasonal messages, announcements, special opening hours, campaigns, reminders and other temporary content.

Getting Started

After installing wgHoliday, open the module from the XOOPS administration area.

  1. Open Administration → Modules.
  2. Open wgHoliday.
  3. Create your first event.
  4. Define the event dates and display options.
  5. Save the event and check the result on the front end.
Recommended workflow: Create the event first, configure its date range and status, and then decide whether it should appear on the website, in a modal window, or through the Events Spotlight block.

Managing Events

The event administration area is the central part of wgHoliday. It allows administrators to create and maintain all holidays and events.

Available actions

  • Add Event – create a new event.
  • Edit Event – modify an existing event.
  • Clone Event – create a copy of an existing event.
  • Delete Event – remove an event.

Cloning is particularly useful when several events use a similar layout or content structure.

Event Content

An event can contain several content areas. This makes it possible to create simple holiday notices as well as more detailed announcements.

Field Purpose
Title The main title of the event.
Header Optional content displayed before the main body.
Body The main event content.
Footer Optional additional content displayed after the body.
Image An optional image associated with the event.

The selected XOOPS editor can be used for the event content. The available editor depends on the editors installed in your XOOPS system.

Display Options

wgHoliday allows you to control how an event element is presented to visitors. This is useful if you want to make different views of spotlight block and modal window.

Website display

An event element can be displayed directly on the module's front-end pages.

Modal display

An event element can also be configured for display in a modal window.

Both

When appropriate, an event can be displayed both on the website and in a modal window.

Do not display

Events that should remain stored but should not currently be shown can be disabled.

Setting validity of event

wgHoliday allows you to control when an event element is presented to visitors.

You can select between two possibilites, which you can define in module preferences:

  • Simple setting an event manually on- or offline
  • Use the event start and end dates to control the period in which an event is considered active.

Simple setting an event manually on- or offline

The status of an event can be changed simply with clicking on the status symbol or by editing an event and setting "Status" to your wish.

Define a date from and date to when the event should be sho

You can define a date from and date end in advance and then the events will be shown/hidded automatically.

Event Images

Images can be attached to events and positioned relative to the event body.

Available image positions

  • Before the body
  • Left of the body
  • Right of the body
  • After the body

Image upload restrictions can be controlled through the module configuration.

Administrators can configure the maximum image size, accepted image MIME types, maximum width and maximum height.

Important: The effective upload size is also affected by the PHP settings upload_max_filesize and post_max_size.

Events Spotlight

wgHoliday works primary with an Events Spotlight block. The block should be used to highlight an event outside the normal module content.

  1. Open the XOOPS block administration.
  2. Locate the Events Spotlight block.
  3. Place the block in the desired theme position.
  4. Configure the block according to your requirements.
  5. Save the block settings.

The spotlight block is especially useful for displaying important upcoming holidays, seasonal information or temporary announcements in a sidebar or another block position.

Permissions

XOOPS permissions should be configured according to the roles used on your website.

If users should be allowed to submit events from the front end, make sure the corresponding XOOPS permissions are enabled for their user group.

Security recommendation: Only grant event administration and deletion permissions to trusted user groups.

Troubleshooting

The event is not visible

  • Check whether the event is enabled.
  • Check the event start and end dates.
  • Check the selected display mode.
  • Check the permissions of the current user group.
  • Clear the XOOPS cache if necessary.

The image cannot be uploaded

  • Check the configured maximum image size.
  • Check whether the image MIME type is allowed.
  • Check PHP upload_max_filesize.
  • Check PHP post_max_size.
  • Check the configured maximum image dimensions.

The spotlight block does not appear

  • Check that the block is enabled.
  • Check the block placement in XOOPS.
  • Check block permissions.
  • Check that suitable events are available.
  • Clear the XOOPS cache.
